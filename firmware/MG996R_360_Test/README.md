# 舊送料 MG996R 360° 獨立測試

此 sketch 只保留給舊版上游送料 360° MG996R 的獨立診斷，不連接 Django、HC-SR04 或三站流程。ADR-0016 已將正式送料馬達改為 XINHUI `60KG`，此程式不得作為現行送料規格。上電後只輸出 `1500 us` 停止脈波；按下 ESP32 內建 `BOOT` 按鈕後，馬達以 `1350 us` 旋轉 `5000 ms`，再自動回到停止脈波。

## 接線

```text
ESP32 GPIO 23 ── MG996R 訊號線
ESP32 GPIO 0 ──── 內建 BOOT 按鈕（按下為 LOW）
獨立 6.0 V 測試電源正極 ───── MG996R 正極
獨立 6.0 V 測試電源負極 ──┬─ MG996R 負極
                            └─ ESP32 GND
```

- MG996R 不得由 ESP32 的 `3.3 V`、`5 V` 或 `VIN` 供電。
- ESP32 上電或重新啟動時不要按住 `BOOT`，否則可能進入下載模式。
- 測試前卸除撥片或讓輸出軸保持無負載，確認旋轉範圍內沒有人手、線材或障礙物。
- 測試電源須能承受伺服啟動電流，並與 ESP32 共地；MG996R 不得接到現行 XINHUI 的 `8.4 V` 電源軌。
- 若馬達異音、抖動、線材發熱或 ESP32 重新啟動，立即切斷測試電源。
- 2026-08-12 發生過不明放電／電擊感與電腦短暫黑屏。接上 ESP32 前，先完全斷電檢查極性、裸線、平台金屬件、USB 回灌路徑與共地；獨立測試時不得同時接上其他伺服電源。

## 使用方式

1. 使用 `esp32:esp32:esp32` 與 `ESP32Servo 3.2.1` 編譯並燒錄 `MG996R_360_Test.ino`。
2. ESP32 啟動後，確認馬達停在 `1500 us`，不會自行旋轉。
3. 短按一次內建 `BOOT` 按鈕，馬達會以 `1350 us` 旋轉 `5000 ms`，再自動停止。
4. 長按只會觸發一次；必須放開後重新按下，才會再次運轉。

若要觀察狀態或手動測試其他數值，可開啟 `115200 baud` Serial Monitor，Line ending 使用 `Newline` 或 `Both NL & CR`：

可用命令：

```text
status
stop
stop 1500
run 1300 1000
run 1350 5000
run 1700 1000
help
```

`run` 限制脈波為 `1000～2000 us`、`10 us` 間距，運轉時間為 `100～5000 ms`。任意時刻送出 `stop` 可立即停止；程式不接受無時間上限的連續運轉命令。馬達已經運轉時，新的按鈕或 Serial 運轉要求不會延長時間。

若 `1500 us` 仍會緩慢爬行，可在 `1400～1600 us` 內以 `5 us` 為間距尋找停止值，例如：

```text
stop 1495
```

找到的停止值只存在本次開機記憶體中，不會寫入 Flash，也不得套用到現行 XINHUI 送料設定。完成獨立診斷後，重新燒錄 `firmware/Three_Gate_Data_Collection/Three_Gate_Data_Collection.ino`；XINHUI 的停止與驅動脈波必須依 [資料採集規格](../../docs/DATA_COLLECTION_SPEC.md) 重新校正。
