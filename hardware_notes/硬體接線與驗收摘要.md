# 硬體接線與驗收摘要

本文件集中硬體接線安全、上電檢查與實機驗收。GPIO、角度、分類 code、距離與 timing 以 [`docs/DATA_COLLECTION_SPEC.md`](../docs/DATA_COLLECTION_SPEC.md) 為唯一來源；平台尺寸、機構演進與維修觀察見 [`docs/HARDWARE_DEVELOPMENT_REPORT.md`](../docs/HARDWARE_DEVELOPMENT_REPORT.md)。

## 供電與共地

- ESP32、HC-SR04、三站 SG90、送料 SG90、MG996R 與所有外部電源必須共地。
- SG90 與 MG996R 使用足以供應瞬間電流的外部伺服電源。
- 不得由 ESP32 的 `3.3 V` 腳供電；MG996R 也不得由 ESP32 的 `5 V` 腳直接供電。
- 上電時觀察電壓降、線材溫升、伺服異音與 ESP32 是否重新啟動。

### 四顆 SG90 共用 4 顆 AA 鹼性電池

目前原型讓三站與送料共四顆 SG90 並聯使用同一個 4 顆 AA 鹼性電池盒：

```text
4 × AA 正極 ── 麵包板正電源軌 ── 四顆 SG90 正極
4 × AA 負極 ── 麵包板負電源軌 ── 四顆 SG90 負極
                                      │
ESP32 GND ────────────────────────────┘

ESP32 各訊號 GPIO（依資料採集規格）── 各 SG90 訊號線
```

- ESP32 使用自己的電源；電池盒正極不得接到 ESP32 `5 V`／`VIN`。
- 拆下或分段的麵包板電源軌必須先用導通檔確認實際連通範圍，不可只依紅藍線判斷。
- 4 顆 SG90 的正負極是並聯，禁止串接伺服或交換任一顆的電源極性。
- TowerPro 對連續旋轉 SG90 標示的工作電壓為 [`4.8～6 V`](https://towerpro.com.tw/product/sg90-360-degree-continuous-rotation-servo/)。首次接入第 4 顆馬達時，必須量測電池組空載與動作中電壓，超出實際馬達額定範圍不得上機。
- 既有三顆 SG90 實地運作正常可作為基準，但不能取代加入第 4 顆後的整合驗收。

## HC-SR04 Echo 電壓安全

HC-SR04 使用 `5 V` 供電時，Echo 會輸出接近 `5 V` 的脈波。ESP32 GPIO 不耐受 `5 V`，Echo 必須先經分壓或邏輯電平轉換。

建議分壓：

```text
HC-SR04 Echo --- R1 2.2 kΩ ---+--- ESP32 Echo input
                              |
                            R2 3.3 kΩ
                              |
GND --------------------------+--- ESP32 GND
```

以 `5.0 V` Echo 計算，輸入端約為 `3.0 V`。`R1` 是 Echo 到輸入端的上方電阻，`R2` 是輸入端到 GND 的下方電阻；兩者裝反會造成過壓。

正常目標為 ≤ `3.3 V`，絕不可超過 `3.6 V`，以萬用表或示波器實測為準。禁止用單一串聯電阻取代分壓。

## 伺服接線與機械檢查

- 訊號線依資料採集規格接線，不因新增裝置任意交換。
- 上電前手動檢查三站閘門與分類器的完整行程，確認不碰硬限位、軌道或相鄰連桿。
- 三站閘門與分類器必須能安全歸位。
- MG996R 沒有位置回授；completed 只表示控制時序完成。
- 送料 SG90 沒有位置回授；`feed_cycle_completed` 只表示計時動作已停止。Dashboard「暫停」是優雅暫停，不是實體緊急斷電。

## 上電前檢查

1. 斷電檢查極性、分壓電阻位置、訊號線與所有 GND。
2. 先啟動 HC-SR04 與 ESP32，量測 Echo 輸入峰值。
3. 接回伺服外部電源，再次量測並檢查電源壓降。
4. 不接果實，確認所有伺服能依規格歸位。
5. 以 Serial log 確認裝置成功初始化，且沒有重複 attach 或 reset。

## 實機驗收

1. 依資料採集規格完成空軌感測、三站停止拍攝與首張延遲驗收。
2. 確認不同尺寸、形狀與蒂頭方向的果實能依序攔截與放行。
3. 依規格逐一驗證四個分類出口、歷史 alias、未知 code 與安全歸位。
4. 重送相同 `command_id`，確認實體動作不重複。
5. 動作期間中斷網路，恢復後只重送 report。
6. 以高速錄影確認三站流程結束後才開始實體分類。
7. 確認分類器錯誤復原不會驅動三站閘門。
8. 空料斗校正送料停止脈波、順時針方向與約 `90°` 單次時間，確認停止時沒有爬行。
9. 混合尺寸、形狀與蒂頭方向，連續完成 `20` 顆單顆送料與完整分類；每次 `feed_one` 恰好一顆、無漏送／雙送、馬達確實停止，且無須人工重對送料桿。
10. 同一段 `20` 顆測試確認四顆 SG90 無抖動／異音、ESP32 無 reset、麵包板及線材無異常溫升，電池組電壓保持在額定範圍。任一項失敗，修正後重新累計連續 `20` 顆。
11. 操作員記錄實體觀察與量測結果；軟體測試與 log 只能輔助判讀，不得代替實體驗收。
