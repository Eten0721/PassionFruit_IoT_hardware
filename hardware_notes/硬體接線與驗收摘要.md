# 硬體接線與驗收摘要

本文件集中硬體接線安全、上電檢查與實機驗收。GPIO、角度、分類 code、距離與 timing 以 [`docs/DATA_COLLECTION_SPEC.md`](../docs/DATA_COLLECTION_SPEC.md) 為唯一來源；平台尺寸、機構演進與維修觀察見 [`docs/HARDWARE_DEVELOPMENT_REPORT.md`](../docs/HARDWARE_DEVELOPMENT_REPORT.md)。

## 供電與共地

- ESP32、HC-SR04、四顆 SG90、送料 MG996R、分類器 MG996R 與兩組外部電源必須共地。
- 伺服不得由 ESP32 的 `3.3 V`、`5 V` 或 `VIN` 腳供電。
- 上電時觀察電壓降、線材溫升、伺服異音與 ESP32 是否重新啟動。

### 兩組 4 顆 AA 電池盒

最終配置使用兩組彼此獨立的 `4 × AA` 電池盒，每組內的伺服採並聯供電：

```text
電池盒 A（4 × AA）正極 ──┬── 送料 360° MG996R 正極
                           └── 分類器位置型 MG996R 正極

電池盒 B（4 × AA）正極 ──┬── Gate 1 SG90 正極
                           ├── Gate 2 SG90 正極
                           ├── Gate 3 SG90 正極
                           └── 分類器擋臂 SG90 正極

電池盒 A 負極 ──┐
電池盒 B 負極 ──┼── ESP32 GND 與全部伺服 GND
ESP32 GND ──────┘

ESP32 各訊號 GPIO（依資料採集規格）── 各伺服訊號線
```

- 兩組電池盒正極不得互接、串接或並接；ESP32 使用自己的電源，兩組電池盒只共用 GND。
- 每個電池盒內使用四顆相同種類、相同新舊程度且電量相近的 AA 電池，禁止混用電池或交換伺服電源極性。
- TowerPro 對 [360° MG996R](https://towerpro.com.tw/product/mg995-robot-servo-360-180-rotation/) 標示的工作電壓為 `4.8～6.6 V`，對 [SG90 360°](https://towerpro.com.tw/product/sg90-360-degree-continuous-rotation-servo/) 標示為 `4.8～6 V`；位置型 MG996R 與其餘 SG90 仍以各自銘牌或原廠規格為準。
- MG996R 的大電流路徑必須使用足以承受負載的電池盒、線材與配電端子；未確認額定電流及動作中溫升前，不得使用麵包板電源軌承載 MG996R 電流。
- 兩組電池盒都必須量測空載與動作中電壓，並檢查電池盒、配電端子及線材溫升。尚未通過量測前，不得宣稱此供電配置已完成驗收。

## HC-SR04 Echo 電壓安全

HC-SR04 使用 `5 V` 供電時，Echo 會輸出接近 `5 V` 的脈波。ESP32 GPIO 不耐受 `5 V`，Echo 必須先經分壓或邏輯電平轉換。

建議分壓：

```text
HC-SR04 Echo --- R1 2.2 kΩ ---+--- ESP32 Echo input
                              |
                            R2 3.3 kΩ
                              |
GND --------------------------+--- ESP32 GND
```

以 `5.0 V` Echo 計算，輸入端約為 `3.0 V`。`R1` 是 Echo 到輸入端的上方電阻，`R2` 是輸入端到 GND 的下方電阻；兩者裝反會造成過壓。

正常目標為 ≤ `3.3 V`，絕不可超過 `3.6 V`，以萬用表或示波器實測為準。禁止用單一串聯電阻取代分壓。

## 伺服接線與機械檢查

- 訊號線依資料採集規格接線，不因新增裝置任意交換。
- 上電前手動檢查三站閘門、分類器及分類器擋臂的完整行程，確認不碰硬限位、軌道或相鄰連桿。
- 三站閘門、分類器與分類器擋臂必須能安全歸位。
- 位置型 MG996R 沒有位置回授；completed 只表示控制時序完成。
- 送料 360° MG996R 沒有位置回授；`feed_cycle_completed` 只表示送料動作已停止。Dashboard「暫停」是優雅暫停，不是實體緊急斷電。
- 一體式送料筒頂部保持開放。Dashboard「優雅暫停」只禁止後續送料，不中止目前 `feed_one`。正常清料必須等待 HC-SR04 或最大運轉時間使 ESP32 回報送料已停止，並目視確認撥片完全靜止後才能伸手。關閉電池盒 A 只保留給緊急狀況；重新送電前必須依資料採集規格完成 terminal report 或 ESP32 重新啟動復原，且手已離開送料筒。恢復供電後必須先執行一次測試送料。
- 分類器擋臂 SG90 的 GPIO、角度與 timing 尚未定案，只記錄其供電歸屬；Issue #2 接受規格前不得接入正式控制流程。

## 上電前檢查

1. 斷電檢查極性、分壓電阻位置、訊號線與所有 GND。
2. 先啟動 HC-SR04 與 ESP32，量測 Echo 輸入峰值。
3. 接回伺服外部電源，再次量測並檢查電源壓降。
4. 不接果實，確認所有伺服能依規格歸位。
5. 以 Serial log 確認裝置成功初始化，且沒有重複 attach 或 reset。

## 實機驗收

1. 依資料採集規格完成空軌感測、三站停止拍攝與首張延遲驗收。
2. 確認不同尺寸、形狀與蒂頭方向的果實能依序攔截與放行。
3. 依規格逐一驗證四個分類出口、歷史 alias、未知 code 與安全歸位。
4. 重送相同 `command_id`，確認實體動作不重複。
5. 動作期間中斷網路，恢復後只重送 report。
6. 以高速錄影確認三站流程結束後才開始實體分類。
7. 確認分類器錯誤復原不會驅動三站閘門。
8. 空送料筒校正送料停止脈波，確認沒有爬行；再以 `10` 顆執行目前階段的機構驗證，自行調整能可靠撥動果實且不造成雙送的最慢驅動脈波，以及 `1000～20000 ms` 範圍內的最大運轉時間。
9. 現階段使用同一批 `10` 顆、不補回已送出的果實，連續驗證剩餘量由 `10` 顆降至 `1` 顆；正式階段仍需以混合尺寸、形狀與蒂頭方向連續完成 `20` 顆單顆送料與完整分類。每次 `feed_one` 都要恰好一顆、無漏送／雙送、馬達確實停止，且無須人工重對撥片。
10. 同一段 `20` 顆測試確認兩顆 MG996R 與四顆 SG90 無抖動／異音、ESP32 無 reset，兩組電池盒的空載與動作中電壓保持在所接伺服的額定範圍，且電池盒、配電端子及線材無異常溫升。任一項失敗，修正後重新累計連續 `20` 顆。
11. 操作員記錄實體觀察與量測結果；軟體測試與 log 只能輔助判讀，不得代替實體驗收。
