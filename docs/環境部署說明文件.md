# 百香果 IoT 系統環境部署說明

[回到專案首頁](../README.md)

Windows 電腦執行 Django，手機透過 `/camera/` 拍照，ESP32 則控制三個拍攝平台閘門、上游送料與分類器。本文說明如何在 Windows 電腦復現並啟動系統；伺服供電與共地方式見 [硬體接線與驗收摘要](../record_image/硬體接線與驗收摘要.md)。

## 1. 下載專案

先安裝 Git 與 Git LFS，再於 PowerShell 執行：

```powershell
git lfs install
git clone https://github.com/Eten0721/PassionFruit_IoT_hardware.git
cd PassionFruit_IoT_hardware
git lfs pull
Get-Item Django_Server\models\ROI.pt,Django_Server\models\Color.pt,Django_Server\models\Wrinkle.pt,Django_Server\models\Defect.pt
```

四個檔案必須是 Git LFS 下載後的實際權重，不可只留下文字 pointer。Django 固定從 `Django_Server/models/` 讀取這四個檔名，不使用 `external/` 內的候選權重。

## 2. 建立或啟用 `PF` 環境

硬體與模型開發統一使用 Python `3.14.4` 的 `PF` Conda 環境。先確認環境是否存在；尚未建立時才執行 `conda create`：

```powershell
conda env list
conda create -n PF python=3.14.4 pip -y
conda activate PF
python --version
```

`python --version` 應顯示：

```text
Python 3.14.4
```

模型端的 CUDA 版 PyTorch 由模型 Repository 維護；全新重建 `PF` 時依 [`external/README.md`](../external/README.md) 進一步安裝模型依賴。

## 3. 安裝 Django 並建立本機設定

確認目前位於 Repository 根目錄，且虛擬環境已啟用：

```powershell
python -s -m pip install -r Django_Server\requirements.txt
python -s -m pip check
Copy-Item .env.example .env
python -s -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
notepad .env
```

將剛才產生的字串填入 `.env`：

```dotenv
DJANGO_SECRET_KEY=貼上剛才產生的隨機字串
```

目前資料採集由檔案系統管理，不使用 Django database model，因此不需要執行 migration。硬體端固定使用 Django `5.2.16` LTS 與 `django-sslserver-v2`；後者保留既有的 `runsslserver` command。Python `-s` 會停用 user-site，避免使用者層套件遮蔽 `PF` 內的版本。

## 4. A Plan：使用 iPhone 個人熱點

預設讓 Windows 電腦、ESP32 與拍照手機使用同一個 iPhone 個人熱點，Django 電腦固定為 `172.20.10.3`。

### 固定 Windows 電腦 IP

1. 先讓 Windows 電腦以自動取得 IP 的方式連上 iPhone 熱點。
2. 執行 `ipconfig /all`，記下 Wi-Fi 的 Subnet Mask；gateway 預期為 `172.20.10.1`。
3. 按 `Win + R`，輸入 `ncpa.cpl`。
4. 對「Wi-Fi」按右鍵，依序選擇「內容」與「網際網路通訊協定第 4 版（TCP/IPv4）」。
5. 選擇「使用下列的 IP 位址」，填入：
   - IP 位址：`172.20.10.3`
   - 子網路遮罩：使用前一步 `ipconfig /all` 顯示的值
   - 預設閘道：`172.20.10.1`
   - 慣用 DNS：`172.20.10.1`
6. 重新連線後執行 `ipconfig`，確認 IPv4 已變成 `172.20.10.3`。

不要在沒有確認的情況下固定填入 `255.255.255.0`；子網路遮罩以 iPhone 熱點當下提供的值為準。

### 開放 Windows 防火牆

以系統管理員身分開啟 PowerShell：

```powershell
Set-NetConnectionProfile -InterfaceAlias "Wi-Fi" -NetworkCategory Private
New-NetFirewallRule -DisplayName "PassionFruit Django 8000" -Direction Inbound -Action Allow -Protocol TCP -LocalPort 8000 -Profile Private -RemoteAddress LocalSubnet
```

### 確認 ESP32 Server

正式 Firmware 的本機設定檔位於：

```text
firmware/Three_Gate_Data_Collection/secrets.h
```

A Plan 使用 `172.20.10.3` 作為 Django 主機。複製 `secrets.example.h` 後只替換主機 IP 與 Wi-Fi credentials，不修改範例中的 endpoint path；API 定義見 [拍攝、檢測與分類規格](CAPTURE_SPEC.md)。

`secrets.h` 也必須填入 iPhone 熱點的 SSID 與密碼，而且不可提交到 Git。

## 5. 啟動系統

在 `Django_Server` 目錄執行：

```powershell
python -s manage.py runsslserver 0.0.0.0:8000
```

電腦開啟 Dashboard：

```text
https://172.20.10.3:8000/dashboard/
```

手機開啟相機頁：

```text
https://172.20.10.3:8000/camera/
```

第一次開啟會顯示自簽憑證警告。確認網址是自己的 Django 電腦後，選擇繼續前往並允許相機權限。手機頁面使用期間不可鎖定螢幕或切到背景。

部署成功時應符合：

- 電腦可以開啟 Dashboard。
- 手機可以開啟相機並顯示預覽。
- ESP32 Serial 顯示 Wi-Fi connected，且能向 Django 輪詢 command。

## 6. B Plan：改用其他 Wi-Fi

離開 iPhone 熱點後，原本固定的 `172.20.10.3` 不能直接帶到其他網路使用。

1. 到 Windows 的 TCP/IPv4 設定，改回「自動取得 IP 位址」與「自動取得 DNS 伺服器位址」。
2. 讓 Windows 電腦與手機連上相同的 Wi-Fi；不要使用訪客網路。
3. 執行 `ipconfig`，找到實際 Wi-Fi IPv4，例如 `192.168.0.54`。
4. 若本機還沒有 `secrets.h`，先於 Repository 根目錄執行：

```powershell
Copy-Item firmware\Three_Gate_Data_Collection\secrets.example.h firmware\Three_Gate_Data_Collection\secrets.h
```

5. 修改 `firmware/Three_Gate_Data_Collection/secrets.h` 的四項設定：
   - `ssid`：Wi-Fi 名稱
   - `password`：Wi-Fi 密碼
   - `commandUrl`：改成新的電腦 IPv4
   - `reportUrl`：改成新的電腦 IPv4
6. 使用既有的 ESP32 燒錄環境重新燒入正式 Firmware。若尚未準備燒錄環境，請參閱 [ESP32 快速燒錄準備](../環境部署/README.md)。
7. Django 仍執行 `python -s manage.py runsslserver 0.0.0.0:8000`，不需修改 Django 或 `.env`。
8. 手機改用新的電腦 IP 開啟 `/camera/`。

若新 IP 是 `192.168.0.54`，更新 `secrets.h` 的 Wi-Fi credentials 與兩個 URL 的主機部分；保留範例中的 endpoint path。

```cpp
const char* ssid = "Wi-Fi 名稱";
const char* password = "Wi-Fi 密碼";
```

手機網址則改為：

```text
https://192.168.0.54:8000/camera/
```

如果路由器啟用了 client isolation，裝置之間可能無法連線，此時改回 iPhone 熱點方案。

## 7. Dataset 位置

照片、分類資料與 `metadata.csv` 位於：

```text
Django_Server/dataset/
```

此目錄已被 Git 忽略，`git push` 不會備份 Dataset。需要保留照片時，請另外備份整個 `Django_Server/dataset/`。
