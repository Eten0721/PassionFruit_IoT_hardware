# Triage Labels

| Canonical role | GitHub label | 用途 |
|---|---|---|
| `needs-triage` | `needs-triage` | 等待 maintainer 評估 |
| `needs-info` | `needs-info` | 等待補充資訊 |
| `ready-for-agent` | `ready-for-agent` | 規格完整，可交給 agent |
| `ready-for-human` | `ready-for-human` | 需要人工執行 |
| `wontfix` | `wontfix` | 不處理 |

技能提到 canonical role 時，使用對應的 GitHub label。
