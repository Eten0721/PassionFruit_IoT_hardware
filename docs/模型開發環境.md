# 模型開發環境

本文件只供模型訓練開發使用。Django 正式部署與權重替換不需要模型 Repository 或 Dataset，請依 [部署與操作說明](環境部署說明文件.md) 執行；Repository 責任邊界以 [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md) 為準。

## 本機位置

| 項目 | 位置 |
|---|---|
| 模型 Repository | [`fcu-passionfruit-project/ps-quality-detection-system`](https://github.com/fcu-passionfruit-project/ps-quality-detection-system) |
| 本機 checkout | `D:\ps-quality-detection-system\`，與硬體 Repository 並列，不放在硬體 Repository 內 |
| Dataset 實體 | `D:\passion-fruit-datasets\` |
| 模型端 `dataset/` | ignored Windows junction，指向 Dataset 實體目錄 |

首次建立 checkout：

```powershell
git clone https://github.com/fcu-passionfruit-project/ps-quality-detection-system.git D:\ps-quality-detection-system
```

兩個 Repository 各自執行 `git status`、commit 與 push。Junction 不是備份；快照數量、切分與備份狀態以 [CURRENT_STATUS.md](CURRENT_STATUS.md) 為準。

## 共用 `PF` 開發環境

先依 [部署與操作說明](環境部署說明文件.md#91-手動建立開發環境) 建立 `PF`，再依模型 Repository 的 README 安裝研究環境依賴：

```powershell
C:\Users\qoqoo\anaconda3\envs\PF\python.exe -s -m pip install -r D:\ps-quality-detection-system\requirements.txt
```

`-s` 停用 user-site，避免使用者層套件遮蔽 `PF` 內的版本。
