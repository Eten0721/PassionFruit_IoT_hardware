# ADR-0022：奶蛋博士唯讀 Gemini 助手

- Status: Accepted（目標決策，尚未實作驗收）
- Date: 2026-10-16

## Context

農夫操作時會想隨時了解四級分布與瑕疵（顏色不佳、皺褶、擦傷、炭疽病、蟲咬、畫圖蟲）的出現情形，並希望直接看圖表；也會詢問 Dashboard 啟用伺服器與部署細節，以及百香果病害成因與防治等一般知識。目前這些資訊散在 `detection_summary.csv`、各顆 `result.json` 與 `docs/`，需要人工翻閱。

指導老師另要求系統主動提醒農夫，例如炭疽病比例近來上升時通知加強防疫。

LLM 擅長理解問題，但自行計算統計值時可能產生無法察覺的錯誤數字；本系統又依 [ADR-0018](0018-local-network-onboarding.md) 要求日常操作可在區網獨立運作，且 AI 不得直接控制硬體。

## Decision

在 Dashboard 加入右下角浮動聊天框，後端由 Django 呼叫 Gemini API；奶蛋博士只查詢、不操作。

- **數字由 Django 計算**：Gemini 只透過 function calling 選擇唯讀統計工具與參數（日期區間、級距、瑕疵類別、分組方式），Django 從檢測分區的總表與 `result.json` 算出確定結果，回傳資料與圖表規格。圖表數值直接取自工具輸出，不經 LLM 轉述；前端以放在 `static/` 的 Chart.js 繪製，不依賴 CDN。
- **資料範圍**：只讀檢測分區，含人工接手結果並標示來源；讀取檢測分區所有已判級果實。放棄本輪與待人工處理另列，不併入四級分布。每顆果實的瑕疵觀察沿用 LINE 通知規則，取已完成檢測視角的成功觀察聯集。蒐集分區與歷史目錄不納入。
- **部署問答**：直接將面向使用者的部署文件（快速開始、環境部署說明）整份放入系統指示，不建立 embedding 或向量資料庫；文件內容以本機執行中版本為準。
- **農業知識**：啟用 Gemini 的 Google Search grounding 並在回答附上來源網址；涉及用藥時提醒以植物保護資訊系統與在地農業改良場建議為準。若所選模型不支援同一請求併用搜尋與 function calling，改由後端分流成兩種請求。
- **唯讀邊界**：工具不得開始運轉、切換模式、分類、刪除或建立 motor command；助手輸出不進入狀態機或分類邊界。
- **失敗不影響流程**：無網路、金鑰缺漏、額度或速率限制時回傳具體 reason（如 `assistant_offline`、`assistant_not_configured`、`assistant_quota_exceeded`），聊天框顯示原因，拍攝、檢測與分槽照常運作。
- **憑證與計費**：使用 Google AI Studio 建立的 API key，專案連結帳單帳戶以付費層級使用，對話內容不供模型訓練；另設 Cloud 預算警示與 Django 端每日請求上限。金鑰與模型名稱存於已被 Git 忽略的 `Django_Server/runtime_config/assistant_credentials.json`，不進網頁、log 或結果檔。HTTP 以標準函式庫呼叫 REST API，不新增 SDK 依賴。
- **對話紀錄**：只保存在瀏覽器頁面記憶體，每次請求附上有限輪數；Django 不持久保存對話。
- **主動趨勢提醒**：Django 以可重現的通用規則偵測，各類別以獨立參數表達門檻、最低樣本數與提醒方向；不交給 LLM 決定觸發或發送。
  - 措辭：提醒文字由 Django 固定規則產生，不交給 Gemini；只列偏高類別與注意事項，不帶數字。LINE 訊息另附 Django 以統計核心繪製的統計圖，讓農夫不必另外詢問就能看到偏高程度；圖中數字同樣不經 LLM。進一步解釋由奶蛋博士依使用者詢問提供。
  - 可追溯性：保存提醒當時的統計與規則快照，奶蛋博士透過既有唯讀提醒工具讀取；不得以日後設定或重新計算取代當時資料。舊紀錄沒有明細時明確回報缺漏。
  - 發送：同次檢查合併為一則 LINE Flex 訊息（統計圖加固定文字），各類冷卻期獨立；沿用既有持久待送機制，失敗不影響檢測與分槽。現行規則、快照欄位與訊息格式以 [CAPTURE_SPEC.md](../CAPTURE_SPEC.md#檢測統計與趨勢提醒) 為準。

## Consequences

統計答案可追溯到檢測資料且不會出現模型編造的數字，但能回答的組合受限於已實作的工具參數，新增問法需擴充工具。部署文件整份放入上下文會增加每次請求的 token 成本，文件大幅擴充時須改為依主題選段。Search grounding 可能另計費用，計入預算上限。趨勢提醒在樣本少時容易誤報，最低樣本數與門檻須累積實際檢測資料後校正；它只反映模型觀察到的比例，模型漏檢或誤檢會直接影響提醒。可提醒的瑕疵種類以 YOLO 模型類別為上限，例如擦傷只有單一 `abrasion` 類別，細分需回到模型 Repository 重新標註與訓練，LLM 無法補足。

奶蛋博士的 Gemini 問答需要網際網路；產生趨勢提醒不需 Gemini、金鑰或其額度，LINE 排送仍需網路與 LINE 憑證。LINE 雙向對話需要對外公開的 HTTPS webhook，與區網架構衝突，不在本決策範圍。Google Developer Program 抵免額是否涵蓋 Gemini API 與其到期日，須在帳單頁確認後才能依賴。
