# ADR-0018：區域網路獨立運作與裝置配網

- Status: Accepted（目標決策，尚未實作驗收）
- Date: 2026-10-10

## Context

Demo 目前依賴特定手機熱點與電腦固定 IP，換電腦或 Wi-Fi 會牽動裝置設定。交接後應能由使用者完成配網，無須為此安裝 Arduino 開發環境或重新燒錄。

## Decision

將需要網際網路的初次電腦部署與可離線的日常操作分開，採區域網路內的 Django 中央控制架構；ESP32 由自身設定熱點提供配網，手機沿用 Chrome 相機頁。選擇這個範圍是為了讓現場更換網路不依賴外部服務，並沿用既有拍攝、控制與人工復原邊界。

已確認的操作需求集中於 [CAPTURE_SPEC.md](../CAPTURE_SPEC.md)「裝置網路連線目標」，本 ADR 不另訂協定、數值或復原時序。mDNS、雲端服務、憑證工具與多主機配對均未因此決議採用。

## Consequences

首次安裝可下載套件，離線運作則須驗證頁面資源、服務探索與影像連線沒有必要的外網依賴。沿用 Chrome 的成功經驗仍須在新 IP 與新電腦驗證，不能推定 HTTPS 信任問題已解決。

[ADR-0013](0013-django-orchestrated-single-feed-auto-run.md) 的中央狀態來源、冪等與優雅暫停原則仍有效；斷線安全停止是另外的復原情境。現行相機恢復後自動送料與新目標的差異已在規格明示，本次文件紀錄不代表韌體已能依新目標停止。
