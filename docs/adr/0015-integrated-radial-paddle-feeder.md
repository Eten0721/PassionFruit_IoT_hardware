# ADR-0015：一體式徑向撥料送料筒

- Status: Superseded by ADR-0016
- Date: 2026-08-08

> 後續狀態（2026-08-22）：[ADR-0016](0016-hardware-platform-feeder-sorter-redesign.md) 已取代本 ADR 的四片徑向撥片、MG996R 送料馬達與電池盒假設。一體式送料筒與側面出口繼續保留，但分槽盤尺寸及出口幾何須依新機構重新驗收。下文保留為歷史決策背景。

## Context

早期送料機構把儲料漏斗與兩孔旋轉盤分開，依賴相隔 `180°` 的落果孔提供停止餘裕。新版希望用同一個容器完成儲料、攪動與側面出料，並在果實剩餘量低時持續撥動到出口；受現有製作方式限制，MG996R 需直立於筒底中央，難以製作下陷馬達與孔盤結構。

## Decision

上游送料改用頂部開放的一體式送料筒。送料筒內徑為 `20～22 cm`、高度為 `30 cm`；360° MG996R 直立於筒底中央，帶動四片可拆換、具有垂直接觸面的圓角撥片。撥片目標長度為 `9～9.5 cm`，不得摩擦底板或筒壁。馬達本體可直接接觸果實，線材經底座旁的小孔直接離開送料筒，筒內不得留下鬆弛線圈或接頭。

側面出口寬度、出口擋板向筒內延伸長度，以及擋板下緣距底板高度都採 `9 cm`。出口直接對齊拍攝平台起點，不增加導料斜道；出口下緣與平台表面的高低差為 `8.5～9 cm`。新版不使用落果孔或固定角度計量，單顆送料由出口擋板、HC-SR04 正常停止與實機觀察共同驗證。

HC-SR04、GPIO `23`、ESP32 本機停止、command 冪等與不自動補轉維持 ADR-0014 的決策。`feeder_max_run_ms` 保留為空筒、卡料或果實未抵達的有限安全上限，改用秒級可調範圍；現行數值以 `CAPTURE_SPEC.md` 為準。Dashboard 維持優雅暫停，不新增送料期間的網路中止輪詢；關閉電池盒 A 只用於緊急停止，復原後必須重新執行測試送料。

## Consequences

徑向撥片比兩孔盤容易依現有工法製作，也能在低裝載量下持續攪動果實；它無法從幾何上保證一次只出一顆，因此正式自動運轉前必須以同一批 `10` 顆、不補回已送出果實的方式，連續驗證剩餘量由 `10` 顆降至 `1` 顆，並另做一次空筒安全逾時。超過 `10` 顆、正式安全填料線與混合果形的完整 `20` 顆流程仍需後續驗收。

若測試仍出現雙送、卡料、撥片停滯、果實彈出軌道或無法可靠起轉，先調整驅動脈波、撥片間隙與出口幾何；仍無法通過時，改評估具有單顆容納槽的計量轉子。本 ADR 取代 ADR-0014 中兩個 `180°` 落果洞與半圈停止餘裕的機構假設，不取代其 HC-SR04 終止送料與有限安全逾時決策。
