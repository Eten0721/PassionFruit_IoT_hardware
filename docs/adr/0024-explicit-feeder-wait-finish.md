# ADR-0024：明確結束送料逾時等待後開放設定

- Status: Accepted
- Date: 2026-10-27
- Extends: [ADR-0014](0014-hcsr04-terminated-upstream-feed.md)、[ADR-0020](0020-single-network-recovery-policy.md)

## Context

送料逾時後，重新開始允許解除等待並送料，模式與 Django／ESP32 網路設定卻仍被等待狀態阻擋。操作員無法單純結束工作後更改設定；開始按鈕與停用提示也使用不同條件。

操作員確認現有硬體設計不需以出口卡果作為額外限制，並接受透過明確確認結束等待、雙端回到閒置後開放設定。

## Decision

Dashboard 提供「結束送料等待」，在本輪沒有待處理資料或動作時，經人工確認後沿用既有 `recover_network` 歸位與雙端提交交握；不新增 Firmware command，也不只清除 Django 旗標。

復原政策持久保存這次操作不恢復自動運轉的意圖，重啟與重試皆保留。完成後禁止自動觸發並回到閒置，開放模式與網路設定；下一次正式開始才重新啟用送料。未確認結束前，原有延遲果實接手契約仍有效；其他失聯、分槽與資料鎖仍依各自政策處理。

前端開始提示使用與開始按鈕相同的恢復條件，避免可操作卻顯示「系統尚未閒置」。API、條件與 UI 契約只在 [CAPTURE_SPEC.md](../CAPTURE_SPEC.md#安全逾時感測異常與延遲抵達) 維護。

## Consequences

結束等待會執行既有馬達歸位，操作前須確認本輪已清空且手已離開。完整交握完成前仍不可切換；失敗後可依既有復原入口重試，不會為了切換設定而額外送料。已支援現行交握的 Firmware 不需因本功能重新燒錄。
