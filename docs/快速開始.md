# 快速開始（不含 ESP32）

[回到專案首頁](../README.md)

本文只涵蓋電腦與手機相機的純拍攝流程。ESP32 燒錄與配網、硬體模式、更新版本與發布 Release 見 [完整部署與操作說明](環境部署說明文件.md)。

## 1. 準備電腦與區域網路

- Windows 10／11；首次安裝需要網際網路。
- 電腦與相機手機須加入可**彼此連線的同一區域網路**。

## 2. 首次安裝

### 2.1 下載專案

1. 開啟 [Releases](https://github.com/Eten0721/PassionFruit_IoT_hardware/releases)，在最新版本下載 **Source code (zip)**。
2. **解壓縮到只含英文與數字的資料夾**，例如 `C:\PassionFruit`。不要直接在壓縮檔預覽視窗裡執行。

### 2.2 雙擊啟動系統

雙擊專案根目錄的 **`啟動系統.bat`**。

會自動完成Python虛擬環境建置，與安裝Pytorch等專案所需套件。

首次安裝需要網路，視網速約需 10～30 分鐘。之後每次啟動只比對套件版本，數秒內即可開始檢查；專案更新了套件版本時才會自動補裝。

接著啟動器會檢查模型、LINE 憑證、防火牆規則與連接埠，顯示「推論裝置：cuda」或「推論裝置：cpu」，
有 NVIDIA 顯示卡卻顯示 `cpu` 時，先更新顯示卡驅動程式（CUDA `12.8` 需要 `570` 以上版本）。

任何一步失敗時，視窗會停住並顯示中文原因與紀錄檔位置 `logs\launcher.log`。
依訊息修正後重新雙擊即可，已完成的步驟會自動跳過。

### 2.3 Windows 防火牆

手機要能連進這台電腦，需允許兩條連入規則。只在可信任的網路上做一次：

1. 雙擊 **`首次設定防火牆.bat`**，在 Windows 權限提示按「是」。
2. 目前網路若為「公用網路」，畫面會逐一詢問是否改為「私人網路」。只有可信任的網路才輸入 `Y`；**公共 Wi-Fi 一律略過**。
3. 腳本只新增尚未存在的規則：TCP `8000` 用於 Django HTTPS，UDP `5353` 用於裝置探索。

### 2.4 LINE 通知憑證（要使用 LINE 功能必做）

> [!IMPORTANT]
> **沒有放這個檔案，LINE 加工果通知就無法發送。** 檢測與分槽仍可正常運作，但加工果通知只會留在待送，Dashboard 的「LINE 加工果通知」會顯示「尚未完成設定」。啟動器每次啟動都會檢查，缺少時顯示醒目警告。

1. 到 Discord 文字頻道下載 `notification_credentials.json`。
2. 放到 `Django_Server/runtime_config/notification_credentials.json`；資料夾不存在時先啟動伺服器會自動產生。檔名與位置必須完全相同。
3. 關閉啟動器視窗，再重新雙擊 `啟動系統.bat`。
4. 在 Dashboard 展開「LINE 通知」，確認「LINE 加工果通知」沒有出現「尚未完成設定」，再依需要開啟通知。開關依「使用硬體」與「純拍攝」分開，預設都是關閉。

此json檔含 LINE bot 權杖與 Cloudinary 金鑰，等同 bot 的密碼：

- 已被 `.gitignore` 忽略，**不要**改名、移到其他資料夾、`git add -f`、貼到聊天群組或截圖。
- 下載 ZIP、`git clone`／`git pull` 都不會帶來這個檔案，換電腦或更新版本時要重新放入。
- 懷疑外洩時，到 LINE Developers 重新發行 token、到 Cloudinary 重新產生 API Key，再更新 Discord 頻道上的檔案。

### 2.5 奶蛋博士（選用）

Dashboard 右下角「問奶蛋博士」可查詢檢測統計並畫圖、回答啟動問題與百香果病蟲害知識，需要網路與 Gemini 金鑰；沒有設定時只有助手無法使用，其他功能照常。金鑰取得、帳單、預算警示與 `assistant_credentials.json` 格式見 [部署說明 2.6](環境部署說明文件.md#26-奶蛋博士-gemini-金鑰選用)。


## 3. 啟動 Django 與確認網路

### 3.1 開啟伺服器

雙擊 `啟動系統.bat`。Dashboard 自動開啟後，若瀏覽器顯示憑證警告，選「進階」→「繼續前往」；這是本機自簽 HTTPS 憑證的正常提示。

伺服器執行期間保留啟動器視窗；**關閉視窗或按 `Ctrl+C` 即停止伺服器**。伺服器已在執行時再次雙擊，只會重新開啟 Dashboard。

### 3.2 選擇本次網路

展開頂部「確認本次使用的網路」，選擇目前連線的 Wi-Fi／Ethernet，按「確認使用」。即使只有一個候選，每次 Django 啟動仍要確認。


## 4. 手機相機與第一次操作

1. **確認手機與 Django 使用相同的區網(Wi-Fi)**，用 Chrome 開啟 Dashboard 顯示的相機 QR／網址。
2. 按「開啟相機」並允許權限；確認手機顯示即時畫面、Dashboard 顯示相機就緒。使用期間保持相機頁在前景，不鎖定螢幕。
3. 先選「蒐集模式」＋「純拍攝」，按「開始拍攝」，檢查三張照片都已保存，再完成人工分類。此模式不操作馬達。

## 5. 常見問題

| 現象 | 直接檢查 |
|---|---|
| 手機開不了相機頁 | 使用當次 QR；確認手機與電腦在同一區網、伺服器仍執行，並核對 HTTPS／相機頁診斷。 |
| LINE 通知顯示「尚未完成設定」或群組沒收到 | 確認已依 [2.4 節](#24-line-通知憑證要使用-line-功能必做) 放好 `Django_Server/runtime_config/notification_credentials.json` 並重新雙擊啟動器；再確認目前模式的通知開關已開啟，並查看 Dashboard 顯示的最近錯誤。 |
| 啟動器顯示「模型只有 Git LFS 指標」 | 下載到的 ZIP 不含模型；改從 [Releases](https://github.com/Eten0721/PassionFruit_IoT_hardware/releases) 重新下載，並確認 `ROI.pt` 約 20 MB。 |
| 啟動器顯示「連接埠 8000 目前無法使用」 | 關閉其他 Django 視窗；若沒有其他 Django，通常是 Windows 暫時把 8000 分配給其他程式的連線，等候約 1 分鐘再雙擊，持續發生時重新開機。 |
| 首次安裝中途失敗或網路中斷 | 恢復網路後重新雙擊，已完成步驟會跳過；仍失敗時將 `logs\launcher.log` 交給團隊。 |
